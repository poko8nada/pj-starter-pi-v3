# Readme format

`README.md` and `README.ja.md`, at the project root. Two files: one is English, the other Japanese, and they carry the same sections.

## Skeleton

`product:ready` replaces `README.md` with the first fenced block after this heading. A line in `<...>` is a place to fill.

```md
# <the product's name>

## What is in it

## Getting started

## Checks

## Harness

## Cycle
```

## Skeleton (ja)

`product:ready` replaces `README.ja.md` with the first fenced block after this heading. A line in `<...>` is a place to fill.

```md
# <プロダクトの名前>

## 入っているもの

## 使い始める

## 検査

## ハーネス

## サイクル
```

## Writing

- A section the product does not need is left out.
- The pair stays a pair: a heading added to one is added to the other, in the same order.
- Do not write what the reader can look up.
