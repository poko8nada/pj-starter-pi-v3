# AGENTS.md

## The cycle

- Work happens in cycles. One cycle is one definition (`definition`), then stack, plan, tickets, work and close
- Each stage is a skill in `.pi/skills/`, and that skill says how to run it.

## Project Rules

"Code", "documentation", and "files and directories" must all be properly structured.  
The following are all anti-patterns:

- Logic is written haphazardly in a single file.
- Text is overly long or makes excessive use of bold formatting, obscuring key points.
- The file structure is too flat.
