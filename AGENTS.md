# AGENTS.md

## The cycle

- Work happens in cycles. One cycle is one sheet (`definition`), then stack, plan, tickets, work and close
- Each stage is a skill in `.pi/skills/`, and that skill says how to run it.
- The sheet is agreed with the owner before any code is touched, and that commit freezes it.
- Only `Stack`, `Remarks` and `Retro` are written into it afterwards.

## Rules

1. Write what you saw. A claim you did not check is not an observation, and a number you did not read is not a number.
2. Keep prose and code in agreement, in the same turn.
